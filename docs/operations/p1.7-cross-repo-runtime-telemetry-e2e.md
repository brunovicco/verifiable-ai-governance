This runbook closes P1.7 with a live proof across:

- `multi-agent-credit-desk`;
- released `a2a-otel-kit` `0.5.0`;
- `verifiable-ai-governance`.

## Required repository state

Minimum compatible baselines:

```text
verifiable-ai-governance  ca2998306404af0cf7539893764f69d94230a914 or P1.7d descendant
multi-agent-credit-desk   b326971bbe7910bd94bd45c0cafbaa11a03f8610 or descendant
```

## Governance configuration

Run migration `0012` and the canonical demo seed before the test.

Enable the P1.7a ingestion boundary in the Governance `.env` using a local-only credential:

```env

RUNTIME_TELEMETRY_API_KEYS_JSON={"<canonical-agent-id>":"<local-test-key>"}
```

The same `.env` must describe the database and `AUDIT_HASH_SALT` used by the running Governance API,
because the harness independently recomputes the persisted audit hashes.

Restart Governance after changing these settings.

The canonical Agent ID can be refreshed with:

```bash

uv run python scripts/seed_canonical_demo.py --json
```

The harness reads:

```text
artifacts/demo/canonical-seed-manifest.json
```

unless `--agent-id` is supplied.

## Evidence report

The report is written to:

```text
artifacts/e2e/p1.7-cross-repo-telemetry-live-report.json
```

It intentionally contains only:

- Governance/Credit Desk commit SHAs;
- event IDs;
- event names/outcomes;
- W3C trace/span IDs;
- A2A correlation/request IDs;
- duration;
- structural error type;
- canonical payload digests;
- audit event/hash/predecessor identifiers.

It does not contain:

- the machine credential;
- credit application fields;
- prompts or completions;
- narrative/model output;
- authorization material;
- arbitrary headers;
- raw request/response bodies.

## What the run proves

### Completed event

A real healthy Credit Desk task completes and synchronously emits
`decisao_agent.evaluation.completed`. Governance authenticates the producer, persists the normalized
record and exposes the exact A2A context/task correlation plus active trace/span IDs.

### Failed event

A real malformed-input task fails and emits `decisao_agent.evaluation.failed` with
`error_type=ValidationError`, without copying the exception message or invalid request content.

### Audit evidence

For both event IDs, the harness reads the real Governance audit rows and independently recomputes
the canonical SHA-256 event hash using the configured `AUDIT_HASH_SALT`. Each non-null
`previous_hash` must resolve to a real audit row.

No production trust boundary is bypassed during the proof.
