# Document templates

Templates humanos, versionados e independentes da interface. O portal futuramente
usará schemas estruturados para gerar instâncias, mantendo `template_id`, versão,
owner, aprovadores, referências e histórico de alterações.

Nenhum template emite parecer jurídico ou aprovação automaticamente. Campos marcados
como obrigatórios devem permanecer bloqueantes até revisão da área responsável.
